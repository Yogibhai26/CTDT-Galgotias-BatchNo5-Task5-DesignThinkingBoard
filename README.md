# CTDT-Galgotias-BatchNo5-Task5-DesignThinkingBoard

## Course

Critical Thinking, Design Thinking, Leadership and Teamwork

## Task

Design Thinking Board

## Product

E-Commerce Website

## Problem Statement

Many customers add products to their shopping cart but leave the website before completing the purchase.

## Design Thinking Process

### Empathize

* Users find checkout lengthy.
* Hidden charges create frustration.
* Mandatory account creation discourages purchases.

### Define

Customers abandon carts because the checkout experience is complicated and time-consuming.

### Ideate

* One-click checkout
* Guest checkout
* Multiple payment options
* Transparent pricing
* Saved delivery information

### Prototype

Design a simplified checkout page with fewer steps and a better user experience.

### Test

Gather customer feedback and analyze checkout completion rates.

## Expected Outcome

* Reduced cart abandonment
* Improved user satisfaction
* Increased sales conversion
